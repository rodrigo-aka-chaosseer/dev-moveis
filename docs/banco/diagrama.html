Lugar e contexto cultural

7 tabelas

locais

já existia

O centro do app — cada lugar, com história, fonte e aviso de visitação.

  • id uuid · pk
  • por_que_conhecer, historia, fonte obrigatórios
  • geom índice espacial p/ busca por proximidade
  • criado_por → usuarios (nulo se a conta foi apagada)

tags_diversidade

já existia

Vocabulário fixo de diversidade.

  • id text · pk (slug)
  • dimensao indígena, afro-brasileira, religiosa...

locais_tags

já existia

Liga um lugar às tags de diversidade que se aplicam a ele.

  • local_id → locais
  • tag_id → tags_diversidade

acessibilidade

já existia

Estrutura física do lugar — informação pública.

  • local_id → locais · pk
  • rampa, elevador, banheiro, piso tátil, Libras, Braille...

ambiente_sensorial

já existia

Ruído, luz, movimento — conforto sensorial, não diagnóstico.

  • local_id → locais · pk
  • ruido, iluminacao, movimentacao, tem_fila

revisoes_local

novo

Fluxo de curadoria — todo lugar passa por aqui antes de valer.

  • autor_id → usuarios (nulo se a conta foi apagada)
  • status rascunho → em revisão → publicado
  • local_id → locais (nulo = proposta nova)

sugestoes_local

novo

Sugestão de lugar pela comunidade, não só pelo time de curadoria.

  • usuario_id → usuarios (nulo se a conta foi apagada)
  • status pendente / aprovada / rejeitada
  • local_id → locais (cascateia — some se o lugar for apagado)

Pessoa e preferências

5 tabelas

usuarios

novo

Perfil de quem tem conta — sem senha, isso é do Supabase Auth.

  • id → auth.users
  • papel membro / curador

preferencias

ganhou dono

Interesses, deslocamento, acessibilidade — dado sensível.

  • usuario_id → usuarios · pk
  • necessidades_acessibilidade privado, só o dono lê

favoritos

ganhou dono

Lugares que a pessoa quer lembrar depois.

  • usuario_id → usuarios
  • local_id → locais

visitas

ganhou dono

Passaporte Cultural — descoberta pessoal, nunca vira ranking.

  • usuario_id → usuarios
  • local_id → locais
  • anotacao, foto_uri privados

avaliacoes

novo

Nota e comentário público sobre um lugar — não é o passaporte.

  • usuario_id → usuarios
  • local_id → locais
  • nota 1 a 5 · comentario

roteiro_paradas

já existia

A sequência de lugares que compõe um roteiro.

  • roteiro_id → roteiros
  • local_id → locais
  • ordem, duracao_min

eventos

Programação com data, ligada a um lugar (ou solta).

  • local_id → locais (opcional)
  • inicio_em, fim_em, fonte
